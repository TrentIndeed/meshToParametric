Frequently asked

What file formats are supported?
STL, OBJ, PLY, and 3MF. The pipeline repairs topology, fixes normals, and removes degenerate faces before processing.
What kinds of parts work best?
Prismatic mechanical parts — brackets, mounts, plates, housings. Components with planar faces, cylindrical holes, pockets, bosses, fillets, and chamfers. Freeform/organic geometry is not supported.
How accurate is the reconstruction?
Typically under 3% volume error compared to the original CAD model. The pipeline detects all major features including through/blind holes, chamfers, and fillets.
Does it require an API key?
No. AI features use the Claude CLI with OAuth authentication — no API key needed. Your Claude Max or Pro subscription handles the cost. The core pipeline works entirely offline without any AI.
Can I self-host it?
Yes. Paramesh AI is open source. Install with pip, run the web viewer locally, and process meshes on your own hardware. No cloud dependency.
How does the AI chatbot work?
The right-panel chat sends your message along with the current feature tree context to Claude. It can describe the part, suggest edits ("make hole 1 larger"), and analyze dimensions before the pipeline runs.
